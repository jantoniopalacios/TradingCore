Parámetros Globales

⚙️ Parámetros Globales - Guía de Uso
1. Qué es / qué configura

Esta pestaña reúne los parámetros generales del backtest: periodo histórico, capital, comisiones, protección de la posición, filtro fundamental y opciones de reporte.

2. Cómo lo usa TradingCore

Estos parámetros no generan por sí mismos una señal técnica de compra o venta. Definen el contexto de ejecución y las reglas globales que se aplican a todas las estrategias.

3. Parámetros de configuración
  • start_date / end_date: delimitan la ventana histórica.
  • intervalo: frecuencia de las velas utilizadas.
  • cash: capital inicial del backtest.
  • commission: coste aplicado a cada operación.
  • stoploss_percentage_below_close: stop loss fijo base.
  • stoploss_swing_enabled / lookback / buffer: protección mediante swing low.
  • breakeven_enabled / breakeven_trigger_pct: suelo de protección respecto al precio de entrada.
  • filtro_fundamental: activa el filtro fundamental.
  • enviar_mail / destinatario_email: opciones de reporte.
4. Condiciones de compra

La pestaña Global no crea una compra. Puede permitir o bloquear una operación mediante filtros globales y de riesgo que se aplican después de que exista una señal técnica válida.

5. Condiciones de venta / bloqueo

Los stops y el break-even pueden provocar o modificar la salida de una posición. El filtro fundamental puede impedir una entrada si está activado y no se cumple su condición.

6. Relación con otros filtros

Estos parámetros actúan como marco común para EMA, RSI, MACD, ATR, Estocástico, Bollinger y Volumen/MoS. No sustituyen a las reglas específicas de cada indicador.

7. Ejemplo práctico
Con un stop loss fijo del 15%, la posición se protege frente a una caída relevante desde la entrada. Si además se activa el stop por swing, TradingCore puede usar un nivel técnico más restrictivo cuando proceda.
8. Advertencias / comportamiento real actual
  • El break-even actual no funciona como un “trigger de beneficio”; define una pérdida máxima tolerada desde la entrada.
  • Valores de ejemplo no deben confundirse con los defaults reales de la configuración activa.
  • Para comparar backtests, conviene mantener constantes fechas, capital, intervalo y comisiones.
