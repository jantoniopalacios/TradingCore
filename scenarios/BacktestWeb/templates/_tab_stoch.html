Parámetros del Estocástico (STOCH)

📊 Estocástico (STOCH) - Guía de uso
1. Qué es / qué mide

El Estocástico compara el cierre actual con el rango reciente de máximos y mínimos. TradingCore trabaja con las líneas %K y %D para detectar cruces y estados de momentum.

2. Cómo lo usa TradingCore

TradingCore evalúa tres variantes independientes: FAST, MID y SLOW. Cada una puede aportar una condición de compra o de bloqueo/venta según la lógica seleccionada.

3. Parámetros de configuración
  • FAST / MID / SLOW: variantes del indicador con sus propios periodos y niveles.
  • buy_logic: selecciona la condición de compra para cada variante.
  • sell_logic: selecciona la condición de bloqueo/venta para cada variante.
  • None / N/A: desactiva esa condición concreta.
4. Condiciones de compra

Según la opción seleccionada, cada variante puede autorizar compra por cruce o por estado ascendente. Las variantes se evalúan de forma independiente siguiendo la lógica configurada.

5. Condiciones de venta / bloqueo

Las opciones de máximo o descendente pueden actuar como condición de bloqueo o salida, según la lógica activa de cada variante.

6. Relación con otros filtros

El Estocástico forma parte de la señal técnica. Aunque dé una señal válida, otros filtros globales como RSI, ATR, Volumen o MoS pueden impedir finalmente la entrada.

7. Ejemplo práctico
Si FAST está configurado para comprar cuando el Estocástico pasa a estado ascendente y esa condición se cumple, puede generar una señal técnica. La operación solo se abrirá si los demás filtros activos también la autorizan.
8. Advertencias / comportamiento real actual
  • FAST, MID y SLOW no son simples etiquetas visuales: se evalúan como variantes independientes.
  • Una lectura de sobrecompra o sobreventa no implica por sí sola una orden.
  • Conviene revisar los periodos y niveles junto con el intervalo del backtest.
