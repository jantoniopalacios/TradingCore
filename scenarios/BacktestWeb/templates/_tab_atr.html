Parámetros de Filtro ATR (Average True Range)

📊 Average True Range (ATR) - Guía de uso
1. Qué es / qué mide

El ATR (Average True Range) mide volatilidad a partir del rango verdadero del precio. TradingCore lo usa para saber si el mercado se está moviendo dentro de un rango de volatilidad aceptable.

2. Cómo lo usa TradingCore

En la implementación actual, ATR no genera señales de compra ni venta por sí solo. Funciona como un filtro de entrada: si está activo, la compra solo puede continuar cuando el ATR se encuentra dentro del rango configurado.

3. Parámetros de configuración
  • atr_enabled: activa o desactiva el filtro.
  • atr_min: valor mínimo de ATR permitido.
  • atr_max: valor máximo de ATR permitido.
4. Condiciones de compra

Si ATR está activo, la compra se autoriza únicamente cuando el ATR actual está dentro del intervalo configurado entre mínimo y máximo.

5. Condiciones de venta / bloqueo

ATR no genera una venta directa. Si el valor está fuera del rango permitido, bloquea la entrada.

6. Relación con otros filtros

ATR actúa como filtro AND dentro del flujo de decisión. Una señal técnica válida puede quedar bloqueada si el nivel de volatilidad no cumple el rango configurado.

7. Ejemplo práctico
Si el rango configurado es 2.0–5.0 y el ATR actual vale 3.4, el filtro permite continuar. Si vale 1.2 o 6.1, la entrada queda bloqueada.
8. Advertencias / comportamiento real actual
  • ATR mide volatilidad, no dirección.
  • Un ATR alto no significa necesariamente señal bajista; solo indica mayor rango de movimiento.
  • Los límites adecuados dependen del activo, intervalo y periodo analizado.
