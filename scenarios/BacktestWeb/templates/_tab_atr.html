Parámetros de Filtro ATR (Average True Range)

📊 Average True Range (ATR) - Guía de Volatilidad
¿Qué hace el ATR aquí?

El ATR (Average True Range) se usa como filtro de rango de volatilidad para entrar. En la implementación actual no genera señales de compra ni venta por sí mismo; solo decide si la compra está permitida según el nivel de volatilidad actual.

⚡ Fórmula que calcula el motor
ATR = EMA del True Range, donde
True Range = max(High - Low, |High - Close anterior|, |Low - Close anterior|)
Regla real del filtro
  • Si atr_enabled está en False: el filtro no se aplica.
  • Si está activo, se exige que el ATR actual esté dentro de [atr_min, atr_max].
  • Si ATR < atr_min: compra bloqueada por baja volatilidad.
  • Si ATR > atr_max: compra bloqueada por exceso de volatilidad.
Valores por defecto observados en código
  • atr_period: 14
  • atr_min: 2.0
  • atr_max: 5.0
  • atr_enabled: False
✅ Resumen
El ATR aquí funciona como filtro de calidad de entrada, no como señal de tendencia. Si está fuera de rango, la compra se aborta. Si está dentro, la estrategia puede continuar con el flujo normal de señales de EMA/RSI/MACD y demás filtros.

⚠️ Relación con otros filtros:
ATR actúa como un filtro AND en el flujo de decisión:
• Si ATR está fuera de rango → Compra bloqueada
• Se aplica después de RSI y antes de volumen
• Independiente de indicadores técnicos (EMA, RSI, MACD, etc.)
💡 Caso de Uso:
Activa ATR si observas que el backtest genera muchos trades en períodos estancados o muy volátiles. Filtra "ruido" y mejora la calidad de las operaciones.
